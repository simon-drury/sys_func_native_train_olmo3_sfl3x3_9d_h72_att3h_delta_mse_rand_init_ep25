# Systemic Functional Computational Language Model

## Canonical identity

This project is a systemic functional computational language model built from scratch.

It is not a modified, dismantled, adapted, reconstructed, or derivative form of another language model. Its architecture, representations, processes, objectives, and documentation must be described through its own systemic functional constituent parts.

## Constituent organization

The computational state is a nine-dimensional systemic functional state organized through the relations among field, tenor, mode, and the ideational, interpersonal, and textual metafunctions.

A sequence is represented as a meaning trajectory. First differences express displacement through the systemic functional state space. State projection carries that displacement into the model’s internal computational dimension. Metafunctional attention processes relations across the trajectory. Trajectory prediction returns a predicted systemic functional displacement. Trajectory loss measures the difference between predicted and observed displacement.

The model therefore operates on systemic functional meaning trajectories and produces systemic functional trajectory predictions. Realization is a distinct systemic functional process.
